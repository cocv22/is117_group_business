## Peer review workflow
Ask the reviewer to open an original source and trace one observed fact to the proposed feature and **planned** check in [the research page](index.html). Record feedback in GitHub issues. For each issue, add a decision (accept/investigate/defer/decline), explain why, link a documentation/code PR or commit, record *real* verification, and request reviewer retry before closing resolved issues. Keep unfinished issues open. No response or actual verification is implied until documented.
